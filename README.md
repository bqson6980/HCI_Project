# 🎨 Interactive Design / HCI Project

Dự án môn học **Tương tác Người - Máy (Human-Computer Interaction - CSC12106)**.  
Repository này chứa toàn bộ tư liệu nghiên cứu người dùng, quy trình thiết kế HCI, mã nguồn giao diện xem trước (prototype) và file báo cáo hoàn chỉnh.

---

## 📁 Cấu trúc Thư mục (Directory Structure)

```text
MyHCIProject/
├── README.md               # File giới thiệu và hướng dẫn tổng quan dự án
├── AGENTS.md               # File quy định & điều phối hướng dẫn AI Agent (OpenCode)
├── docs/                   # File báo cáo chính thức (PDF/Word/Slide) nộp cho giảng viên
├── data/                   # Input: Tư liệu nghiên cứu gốc (ảnh vẽ tay, kịch bản nháp, khảo sát)
├── code/                   # Final Product 1: Mã nguồn Web Prototype chạy thực tế
├── output/                 # Final Product 2: Sản phẩm export từ AI (Hình ảnh sơ đồ, biểu đồ)
├── skills/                 # Các quy trình / kỹ năng cụ thể để AI xử lý công việc
├── rules/                  # Quy chuẩn thiết kế, nguyên tắc HCI & phong cách làm việc
├── templates/              # Các khung mẫu giao diện và định dạng báo cáo
├── tools/                  # Các script tự động hóa (Render HTML -> PNG/PDF)
└── .opencode/              # Thư mục cấu hình local & Custom Tools cho OpenCode CLI
